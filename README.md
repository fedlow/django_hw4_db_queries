# Галерея сотрудников (Django ORM)

Веб-приложение на Django для управления карточками сотрудников, их фотографиями и контроля рассадки за рабочими столами. Проект демонстрирует продвинутую работу с базой данных через Django ORM.

## 📋 Описание проекта

Приложение позволяет вести базу сотрудников, отслеживать их стаж, должности и рабочие места. Реализована строгая валидация рассадки: тестировщики и разработчики не могут сидеть за соседними столами.

**Основные возможности:**
*   **Управление данными:** Модель сотрудника включает ФИО, пол, навыки, дату приема на работу, должность и номер стола. Также поддерживается загрузка галереи фотографий с сортировкой по порядковому номеру.
*   **Валидация:** При добавлении или изменении сотрудника срабатывает проверка, запрещающая сажать QA-инженеров рядом (за соседние столы) с разработчиками (Backend/Frontend).
*   **Главная страница:** Отображает общее количество сотрудников в базе и карточки 4-х последних принятых на работу сотрудников.
*   **Список сотрудников:** Выводит всех сотрудников с пагинацией (по 10 человек на страницу). Карточки содержат первое фото, ФИО, навыки и стаж работы в днях.
*   **Подробная карточка:** Доступна только авторизованным пользователям. Содержит заглавное фото, полную информацию, стаж, номер стола и галерею с остальными фотографиями.
*   **Оптимизация:** Запросы к базе данных оптимизированы с использованием `prefetch_related` и `select_related` для избежания проблемы N+1.
*   **Автоудаление:** Файлы изображений физически удаляются с диска при удалении записей из БД.

## 🛠️ Стек технологий
*   Python 3
*   Django (Class-Based Views, ORM)
*   Pillow (обработка изображений)
*   SQLite (база данных)
*   Black, Isort (форматирование кода и сортировка импортов)

## 🚀 Инструкция по локальному запуску

1. **Клонируйте репозиторий:**

   git clone https://github.com/fedlow/django_hw4_db_queries.git
   
   cd django_hw4_db_queries

### Создайте и активируйте виртуальное окружение:

python -m venv venv

#### Для Windows:
venv\Scripts\activate

#### Для macOS/Linux:
source venv/bin/activate

### Установите зависимости из файла requirements.txt:

pip install -r requirements.txt

### Примените миграции для создания базы данных:

python manage.py migrate


### Создайте суперпользователя для доступа в админку:

python manage.py createsuperuser

### Запустите сервер разработки:

python manage.py runserver


### Откройте в браузере:

Главная страница: http://127.0.0.1:8000/

Список сотрудников: http://127.0.0.1:8000/employees/

Панель администратора: http://127.0.0.1:8000/admin/
